# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [semantic versioning](https://semver.org/).

## [1.0.0] - 2026-10-17

### Added

- The `recipe-to-table` skill:
  - its workflow (`SKILL.md`)
  - the tabular-recipe rules (`references/method.md`)
  - an HTML renderer, plus a Python script that checks recipe JSON
  - three worked examples
- Claude Code plugin and self-hosted marketplace manifests.
- Claude.ai Project instructions and a skill zip build for Claude.ai upload.
- Tests for validation and table layout, and GitHub Actions workflows for CI and releases.
